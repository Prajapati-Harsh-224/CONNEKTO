# Connecto — UI/UX Specification

## 1. Design Goal

The interface must be usable by a small retailer who may have limited familiarity with English or complex software.

The product should prioritize:
- Clarity
- Speed
- Familiar patterns
- Mobile usability
- Local language readiness

## 2. Global Navigation — Shop Owner

Suggested navigation:
- Home
- Suppliers
- Cart
- Orders
- Analytics
- Assistant
- Profile

On mobile, prioritize:
- Home
- Suppliers
- Cart
- Orders

## 5. Visual Rules

- Mobile-first responsive design.
- Use consistent spacing.
- Use reusable cards/components.
- Primary actions should be visually obvious.
- Avoid dense tables on mobile.
- Show price and quantity clearly.
- Cart count must always be visible.
- Order status must be understandable without technical terminology.

## 6. Empty States

Every major list should have an empty state.

Examples:
- "No orders yet"
- "No products found"
- "Your cart is empty"
- "No pending orders"

Each empty state should explain what the user can do next.

## 7. Error States

Examples:
- Network unavailable
- Login failed
- Invalid quantity
- Product unavailable
- Order creation failed

Errors must be human-readable.

## 8. Prototype Data

Use realistic but fictional data when authorization to use real brand assets/data does not exist.

Do not make the UI falsely claim:
- Official brand partnership
- Authorized distributor relationship
- Real inventory
- Real pricing
